# Apartments Manager (RealEstateSoft)

Уеб приложение за управление на сгради, обекти, клиенти и плащания за недвижими имоти.  
Стек: Spring Boot 4.x, Java 17, Spring MVC, Spring Data JPA, Thymeleaf, MySQL.

## Основни възможности
- Сгради и обекти (апартаменти, гаражи, мазета, паркоместа, търговски площи)
- Клиентска база с детайли, покупки и плащания
- Планове за плащане по етапи (Предварителен договор, Акт 14, Акт 15, Акт 16)
- Проследяване на плащания, капаро и статуси
- Импорт/експорт на данни чрез Excel
- Dashboard с ключови статистики и аларми

## Изисквания
- Java 17+
- Maven 3.9+
- MySQL 8+

## Стартиране (локално)
1. Клонирай проекта и отвори директорията
2. Конфигурирай връзката към базата в `src/main/resources/application.properties`
3. Стартирай приложението:
   - `mvn spring-boot:run`
4. Отвори:
   - `http://localhost:8081`

## Конфигурация
Основни настройки са в:
- `src/main/resources/application.properties`
- `src/main/resources/schema.sql` (инициализация/миграции)

## Полезни страници
- ` /buildings` — Сгради
- ` /apartments` — Списък с обекти
- ` /clients` — Клиентска база
- ` /payments` — Плащания

## Бележки
- Валутата в системата е EUR.
- Всички суми се закръглят до 2 знака след десетичната запетая.
